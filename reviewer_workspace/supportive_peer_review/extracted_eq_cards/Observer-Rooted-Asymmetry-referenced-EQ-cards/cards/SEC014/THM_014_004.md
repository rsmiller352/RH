# SI Units Are Observer-Scale Reports — SI seconds, kilograms, joules, action-values, and energy-values are bridge-side observer-scale reporting conventions, not theory-native primitives. The theory determines recoverable relational count / readout content; an SI value is a selected-standard report of that content. Unit rescaling changes the report coefficient and leaves the recoverable construction record invariant. Therefore SI units are not derived from the internal count geometry alone: any attempt to obtain an SI unit requires an admitted comparison standard / calibration convention, hence a bridge input, not a pure internal derivation.

## 0) Governance & Scope Lock

This theorem proves a reporting-status result.

It does **not** build a new bridge.
It does **not** compute an SI value.
It does **not** determine an aperture parameter.
It does **not** close a full magnitude.

It says:

\[
\text{SI value}
\neq
\text{theory-native primitive}.
\]

An SI value is a bridge-side observer-scale report:

\[
\text{SI report}
=
\text{recoverable readout content expressed against a selected comparison standard}.
\]

The selected standard is not produced by pure internal count geometry. It is an admitted comparison standard / calibration convention.

## 1) Plain language

A measured number in SI — so many seconds, so many kilograms, so many joules — looks like a fact about the world. This theorem says it is really a **report**: the theory fixes a recoverable relational count/readout content, and the SI number is that content read against a **chosen** standard (the second, the kilogram, …). Choose a different-sized standard and the number changes — but the underlying content, and the construction record that lets you recover the count, do not. Because *every* rescaling of the standard leaves that content untouched, the content by itself cannot pick out *which* standard is "the" SI one. So an SI unit can never be squeezed out of the internal count geometry alone; getting one always requires admitting an outside comparison standard / calibration convention — a bridge input, not a pure derivation. This is the precise, proved version of the `GATE_001_003` rule "units are reports, not primitives," now carried at the bridge layer where the SI notation actually lives.

## 3) Bridge-Side Report Form

Let \(Q\) be a promoted observer-local readout object whose bridge-side presentation has been admitted by the S07 bridge chain.

Let

\[
B^K_O(Q)
\]

denote the bridge-side presented quantity of kind \(K\), where \(K\) may be a dimensionless screen image, SI action presentation, or SI energy presentation.

Let \(u_K\) be a selected observer-scale unit / comparison standard of the same kind \(K\).

Then the report of \(Q\) in unit \(u_K\) has the form

\[
\operatorname{Rep}^{K}_{u,O}(Q)
=
q^{K}_{u,O}(Q),
\]

with

\[
q^{K}_{u,O}(Q)
:=
\frac{B^K_O(Q)}{u_K}.
\]

This is defined only when the unit standard is admitted:

\[
q^{K}_{u,O}(Q)\downarrow
\Rightarrow
\operatorname{Unit}_L(u_K)
\wedge
\operatorname{Cmp}_L(B^K_O(Q),u_K).
\]

The report is undefined if no standard is supplied:

\[
\neg\exists u_K\,\operatorname{Unit}_L(u_K)
\Rightarrow
\operatorname{Rep}^{K}_{u,O}(Q)\uparrow.
\]

`report_unit` is a **value-level support factor** (the `I` precedent), not a registry glyph.

## 5) Unit-Rescaling Lemma

Let \(u_K\) and \(u'_K\) be two admitted observer-scale standards of the same kind \(K\), with

\[
u'_K=\lambda u_K,
\qquad
\lambda>0.
\]

Then

\[
q^{K}_{u',O}(Q)
=
\frac{B^K_O(Q)}{u'_K}
=
\frac{B^K_O(Q)}{\lambda u_K}
=
\lambda^{-1}q^{K}_{u,O}(Q).
\]

Thus

\[
q^{K}_{u',O}(Q)u'_K
=
\left(\lambda^{-1}q^{K}_{u,O}(Q)\right)
\left(\lambda u_K\right)
=
q^{K}_{u,O}(Q)u_K
=
B^K_O(Q).
\]

So the report coefficient changes, but the bridge-side presented content does not.

The report-equivalence class is

\[
[\operatorname{Rep}^{K}_{O}(Q)]
=
\left\{
(q,u_K)
\;|\;
q\,u_K=B^K_O(Q),
\operatorname{Unit}_L(u_K)
\right\}.
\]

Changing \(u_K\) chooses a different representative of the same report class, not a different internal object, provided the construction record is preserved.

## 6) SI Non-Derivability Theorem

The internal theory can determine count, closure, and readout content.

It cannot, from that content alone, select a unique SI unit representative.

Assume for contradiction that pure internal content determines a unique SI standard:

\[
\operatorname{Derive}_{\mathrm{int}}
\left(
u^{SI}_K
\mid
\operatorname{Rec}_O(Q), B^K_O(Q)
\right).
\]

But for every \(\lambda>0\), the transformed pair

\[
(q,u^{SI}_K)
\mapsto
(\lambda^{-1}q,\lambda u^{SI}_K)
\]

has the same invariant product:

\[
(\lambda^{-1}q)(\lambda u^{SI}_K)
=
q u^{SI}_K
=
B^K_O(Q),
\]

and preserves the same construction record:

\[
\operatorname{Rec}_O(Q)
\mapsto
\operatorname{Rec}_O(Q).
\]

Therefore the internal content fixes only the equivalence class

\[
[(q,u_K)],
\]

not the representative \(u^{SI}_K\).

For \(\lambda\neq1\),

\[
\lambda u^{SI}_K\neq u^{SI}_K,
\]

while the recoverable content is unchanged. Hence the choice of \(u^{SI}_K\) requires an additional convention:

\[
\operatorname{Derive}_{\mathrm{int}}
\left(
u^{SI}_K
\mid
\operatorname{Rec}_O(Q), B^K_O(Q)
\right)
\uparrow.
\]

Equivalently,

\[
\operatorname{SI\ unit}
\notin
\operatorname{PureInternalDerivables}.
\]

An SI unit may enter only through

\[
\exists s\,
\big(
\operatorname{Std}_L(s)
\wedge
\operatorname{Cal}_L(s,u^{SI}_K)
\big),
\]

that is, through an admitted comparison standard and calibration convention.

## 7) Outside-Grid Clause

If a construction claims to derive an SI unit by comparing to an outside grid \(g_{\mathrm{ext}}\), then that grid is not pure internal ground.

It is a comparison standard:

\[
\operatorname{Std}_L(g_{\mathrm{ext}})
\]

or a calibration premise:

\[
\operatorname{Cal}_L(g_{\mathrm{ext}},u^{SI}_K).
\]

Therefore the construction is bridge-side:

\[
g_{\mathrm{ext}}\ \text{used}
\Rightarrow
\text{bridge / calibration input used}.
\]

So it is not a derivation of SI from pure theory-native count geometry.

## 10) Forward Use

A smooth SI-rendered value may be used only as an observer-scale report of recoverable construction content. Unit changes are allowed only when they preserve the construction record and the invariant bridge-side content. SI standards are calibration conventions, not internal primitives.
