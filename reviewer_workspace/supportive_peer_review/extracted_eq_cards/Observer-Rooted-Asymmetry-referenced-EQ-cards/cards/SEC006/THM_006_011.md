## 1) Plain language

The floor card (THM_006_007) already gives us a count: how many whole units of distinguishability
separate two histories. This card says what that count *is* — the **existence counter** — and ties it
back to the very first thing the framework proved. Existence is counted in whole units, and the first
unit is one (that is THM_002_007, proved at the ground layer from a single binary cut). Here, at the
aperture layer, we re-derive the same fact a second way: when the base action-gap reaches exactly one
resolution unit — "base saturation" — exactly one unit of distinguishability has completed, so the
base count is **I = 1 (at base saturation)**. Same value, re-earned from the aperture machinery.

Two disciplines matter. First, this is a **re-derivation, not a re-foundation**: the ground-layer
proof (THM_002_007) stands on its own and does not lean on anything here; we reproduce its value
downstream, never the other way around (that direction is fixed — S01 first, then S05). Second, the
counter never reads zero: an admissible count is one or more (ℤ≥1); "no completed unit yet" is the
record-absent predicate, not "I = 0." The counter excludes zero by its very type.

## 4) Proof / Construction

**(I — I is the existence counter, codomain ℤ≥1.)** By AX_001_001 (the Law of Existence: existence is
relational distinguishability), distinguishability is what is counted; THM_006_007 establishes I as
the count of completed units of distinguishability (the completed-crossing count of g_Φ, forced by
account completion). Existence is counted in whole completed units (THM_002_007), so an admissible
count is ℤ≥1; I = 0 is not an admissible existence value — it is the record-absent predicate
(GUARD_006_006, instancing GUARD_001_008: a zero booking asserts the existence of nothing, a
Law-of-Existence violation). Hence I : (admissible history pairs) → ℤ≥1, with the sub-unit /
no-completed-unit case the record-absent predicate (THM_006_007 §I).

**(II — base saturation ⟹ I = 1 at base saturation, re-derived.)** At base saturation the base action-gap equals
one resolution unit: |g_Φ| = 1 (one whole u_Φ of action-difference, DEF_006_004 the unit). By the
floor (THM_006_007 §II/§III): |g_Φ| reaching the unit is one completed crossing, which forces exactly
one completed-unit posting (ΔI = 1, by non-erasure + paired posting + the unit — LEM_002_013 /
THM_002_012 / THM_002_007, re-grounded at THM_006_007). The completed-crossing count at saturation is
therefore I = ⌊|g_Φ|⌋ |_{|g_Φ|=1} = 1 at base saturation. The value is **read off the saturation** (one unit
completed), not pre-stated.

**(III — consistency with THM_002_007; the re-derivation fence, TD-020.)** THM_002_007 derived I = 1
at S01 — the First Existence Count — from a single binary cut (A | ¬A; only the admitted side enters;
the first admitted support is a singleton, count 1), rooted in AX_001_001. The aperture-layer
value I = 1 at base saturation (II) is the **same value**, re-derived from base saturation via the floor's forcing — a
second, independent route to the first existence count. This is a **re-derivation, not a
re-foundation**: THM_002_007's proof is self-contained at S01 and does **not** depend on this card or
on any S05 object; this card **consumes** THM_002_007 downstream (S01 → S05) and **reproduces** its
value, never grounding it. The construction order is one-directional (the S01 card may not cite S05 —
TD-020); a use of this re-derivation to GROUND THM_002_007 (S01 citing S05) would invert the order and
is rejected (F-S05ctr-3). The two routes AGREE (both = 1), which is the expected consistency of a
single value re-derived at two layers, not a circular grounding. ∎
