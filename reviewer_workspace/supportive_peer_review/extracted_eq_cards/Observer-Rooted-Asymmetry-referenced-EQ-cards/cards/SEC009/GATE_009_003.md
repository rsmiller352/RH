# Recovery Before Scaling — operation-level admissibility gate for smooth magnitudes. A rendered scalar / aperture value / SI report may be compared, ratioed, normalized, or rescaled only after its recoverable count-index package RCI_O(R) is recoverable. The gate applies to operations on already-rendered reports, not to the first rendering step itself: GATE_009_001 gates R -> Y; DEF_009_002 defines RCI_O(R); THM_014_004 proves unit-rescaling preserves report content. This card gates the next act: using Y in smooth-magnitude algebra. No RCI, no lawful scaling/comparison.

## 0) Governance & Scope Lock

This is a **GATE** over operations on rendered smooth magnitudes.

It does not render a readout.

It does not define the recoverable count index.

It does not prove unit-rescaling invariance.

Those are already handled by:

\[
\texttt{GATE\_S07\_070},\qquad
\texttt{DEF\_S07\_077},\qquad
\texttt{THM\_S07\_076}.
\]

This card gates the next act:

\[
\boxed{
\text{using rendered smooth values in comparison / scaling algebra}.
}
\]

The rule is:

\[
\boxed{
\text{No recovery, no lawful scaling or comparison.}
}
\]

## 1) Plain language

A smooth value is not yet safe to compare just because it is written down.

Before a rendered value can be scaled, ratioed, normalized, or compared to another rendered value, the source count-index package must be recoverable.

So the order is:

\[
\text{readout}
\longrightarrow
\text{rendered report}
\longrightarrow
\text{recover RCI}
\longrightarrow
\text{compare / rescale}.
\]

The forbidden shortcut is:

\[
\text{readout}
\longrightarrow
\text{smooth number}
\longrightarrow
\text{scale/compare as if primitive}.
\]

That shortcut loses the count source.

## 2) Prior Gates And The Non-Restatement Boundary

`GATE_009_001` gates the individual rendering step:

\[
R
\longrightarrow
Y.
\]

It requires recorded-construction recovery:

\[
\operatorname{Recover}_O
\left(
Y,
\operatorname{Rec}_O(R)
\right)
=
\operatorname{Count}_O(R).
\]

`DEF_009_002` packages that recovery object as

\[
\operatorname{RCI}_O(R)
=
\left(
\operatorname{Idx}_O(R),
\operatorname{Rec}_O(R)
\right).
\]

`THM_014_004` proves that observer-scale unit reports are rescaling-conventional:

\[
u'=\lambda u,
\qquad
q'=\lambda^{-1}q,
\qquad
q'u'=qu.
\]

This card does something different.

It gates the operation

\[
(Y_1,\dots,Y_n)
\longmapsto
\Phi(Y_1,\dots,Y_n),
\]

where \(\Phi\) may be a comparison, ratio, normalization, common rescaling, or dimensionless shape operation.

Thus the new object is the **operation-level admissibility condition**:

\[
\operatorname{Use}^{\Phi}_O(Y_1,\dots,Y_n)\downarrow.
\]

## 3) Rendered Inputs

Let

\[
R_1,\dots,R_n
\]

be promoted observer-local readout objects.

Let

\[
Y_i
=
\operatorname{Render}_O(R_i;\mathcal A_i)
\]

be rendered smooth reports of those readouts.

By `DEF_009_002`, each source readout has a recoverable count-index package

\[
\operatorname{RCI}_O(R_i)
=
\left(
\operatorname{Idx}_O(R_i),
\operatorname{Rec}_O(R_i)
\right).
\]

Define input recovery admissibility by

\[
\operatorname{RCIAdm}_O(Y_i;R_i)\downarrow
\iff
\operatorname{Recover}_O
\left(
Y_i,
\operatorname{Rec}_O(R_i)
\right)
=
\operatorname{RCI}_O(R_i).
\]

Equivalently,

\[
\operatorname{RCIAdm}_O(Y_i;R_i)\downarrow
\iff
\left[
\pi_1
\operatorname{Recover}_O
\left(
Y_i,
\operatorname{Rec}_O(R_i)
\right)
=
\operatorname{Idx}_O(R_i)
\right]
\]

and

\[
\left[
\pi_2
\operatorname{Recover}_O
\left(
Y_i,
\operatorname{Rec}_O(R_i)
\right)
=
\operatorname{Rec}_O(R_i)
\right].
\]

## 4) Operation Record

Let \(\Phi\) be a smooth-magnitude operation:

\[
\Phi
\in
\{
\text{compare},
\text{ratio},
\text{normalize},
\text{rescale},
\text{shape-function}
\}.
\]

Let

\[
Z
=
\Phi(Y_1,\dots,Y_n)
\]

be the operation result.

The operation must carry its own operation record:

\[
\operatorname{OpRec}_O(\Phi;Y_1,\dots,Y_n),
\]

recording at minimum:

\[
\left(
\Phi,
R_1,\dots,R_n,
\operatorname{Rec}_O(R_1),\dots,\operatorname{Rec}_O(R_n),
u_1,\dots,u_n
\right),
\]

where \(u_i\) are the admitted report standards / units when the operation uses reported scalar values.

This operation record is card-local notation, not a registry glyph.

## 5) Gate Statement

The operation

\[
\operatorname{Use}^{\Phi}_O(Y_1,\dots,Y_n)
\]

is admissible only if every input has recoverable count index and the operation preserves the full recovery tuple.

Formally:

\[
\boxed{
\operatorname{Use}^{\Phi}_O(Y_1,\dots,Y_n)\downarrow
\Rightarrow
\bigwedge_{i=1}^n
\operatorname{RCIAdm}_O(Y_i;R_i)\downarrow
}
\]

and there must exist an operation-level recovery map

\[
\operatorname{Recover}^{\Phi}_O
\]

such that

\[
\boxed{
\operatorname{Recover}^{\Phi}_O
\left(
Z,
\operatorname{OpRec}_O(\Phi;Y_1,\dots,Y_n)
\right)
=
\left(
\operatorname{RCI}_O(R_1),
\dots,
\operatorname{RCI}_O(R_n)
\right).
}
\]

Thus:

\[
\operatorname{Use}^{\Phi}_O(Y_1,\dots,Y_n)\downarrow
\Rightarrow
\operatorname{Recover}^{\Phi}_O
\left(
\Phi(Y_1,\dots,Y_n),
\operatorname{OpRec}_O(\Phi;Y_1,\dots,Y_n)
\right)
=
\left(
\operatorname{RCI}_O(R_i)
\right)_{i=1}^n.
\]

Failure of any input recovery blocks the operation:

\[
\exists j\,
\neg\operatorname{RCIAdm}_O(Y_j;R_j)
\Rightarrow
\operatorname{Use}^{\Phi}_O(Y_1,\dots,Y_n)\uparrow.
\]

## 6) Comparison Gate

A comparison operation

\[
\operatorname{Compare}^{\Phi}_O(Y_1,\dots,Y_n)
\]

is admissible only if:

\[
\bigwedge_{i=1}^n
\operatorname{RCIAdm}_O(Y_i;R_i)\downarrow,
\]

and the comparison standards are admitted in the sense of `GATE_001_003`:

\[
\bigwedge_{i=1}^n
\operatorname{Unit}_L(u_i),
\]

with a licensed comparison relation

\[
\operatorname{Cmp}^{\Phi}_L
\left(
(Y_1,u_1),\dots,(Y_n,u_n)
\right).
\]

Therefore:

\[
\boxed{
\operatorname{Compare}^{\Phi}_O(Y_1,\dots,Y_n)\downarrow
\Rightarrow
\left[
\bigwedge_{i=1}^n
\operatorname{RCIAdm}_O(Y_i;R_i)
\right]
\wedge
\operatorname{Cmp}^{\Phi}_L
\left(
(Y_i,u_i)_{i=1}^n
\right).
}
\]

A comparison between smooth reports whose source indexes are not recoverable is ill-typed:

\[
\neg
\left(
\bigwedge_{i=1}^n
\operatorname{RCIAdm}_O(Y_i;R_i)
\right)
\Rightarrow
\operatorname{Compare}^{\Phi}_O(Y_1,\dots,Y_n)\uparrow.
\]

## 7) Rescaling Gate

Let \(Y\) be a rendered report of \(R\).

A positive rescaling

\[
Y\mapsto Y'
\]

is admissible only if it is either:

1. a unit/report rescaling preserving bridge-side content, or
2. a separately recorded rendering operation whose own recovery returns the same RCI package.

### 7.1 Unit Rescaling

Let

\[
Y
=
q_u(R).
\]

Let

\[
u'=\lambda u,
\qquad
\lambda>0,
\]

and

\[
q_{u'}(R)=\lambda^{-1}q_u(R).
\]

Then by `THM_014_004`,

\[
q_{u'}(R)u'
=
\left(\lambda^{-1}q_u(R)\right)(\lambda u)
=
q_u(R)u.
\]

The bridge-side report content is invariant.

The unit rescaling is admissible only if the recovery package is also invariant:

\[
\boxed{
\operatorname{Recover}_O
\left(
q_{u'}(R),
\operatorname{Rec}_O(R)
\right)
=
\operatorname{RCI}_O(R).
}
\]

So lawful unit rescaling satisfies

\[
\operatorname{RCI}_O(R)
\mapsto
\operatorname{RCI}_O(R).
\]

### 7.2 Bare Scalar Scaling Is Not Unit Rescaling

A bare scalar multiplication

\[
Y'=\lambda Y
\]

with no unit transform, no operation record, and no recovery proof is not admissible:

\[
\lambda Y
\quad\text{alone}\quad
\not\Rightarrow
\operatorname{Use}^{\mathrm{scale}}_O(Y)\downarrow.
\]

Formally:

\[
\neg\exists \operatorname{OpRec}_O(\lambda;Y)
\quad\Rightarrow\quad
\operatorname{Use}^{\mathrm{scale}}_O(\lambda Y)\uparrow.
\]

And if the scaled result cannot recover the same source package,

\[
\operatorname{Recover}^{\lambda}_O
\left(
\lambda Y,
\operatorname{OpRec}_O(\lambda;Y)
\right)
\neq
\operatorname{RCI}_O(R),
\]

then

\[
\operatorname{Use}^{\mathrm{scale}}_O(\lambda Y)\uparrow.
\]

## 8) Dimensionless Shape Operations

A dimensionless operation

\[
Z=\Phi(Y_1,\dots,Y_n)
\]

may cancel common reporting units, but unit cancellation alone is not enough.

It must also preserve recoverability of every source package:

\[
\boxed{
\operatorname{Use}^{\Phi}_O(Y_1,\dots,Y_n)\downarrow
\Rightarrow
\operatorname{Recover}^{\Phi}_O
\left(
Z,
\operatorname{OpRec}_O(\Phi;Y_1,\dots,Y_n)
\right)
=
\left(
\operatorname{RCI}_O(R_1),
\dots,
\operatorname{RCI}_O(R_n)
\right).
}
\]

Thus the operation may discard a common unit scale only if it does not discard the source count indexes.

Unit cancellation:

\[
u_i\mapsto \lambda u_i
\]

may leave \(Z\) invariant, but the gate requires the stronger condition:

\[
Z\ \text{unit-invariant}
\quad\text{and}\quad
(R_i,\operatorname{RCI}_O(R_i))_{i=1}^n
\ \text{recoverable}.
\]

So:

\[
\text{unit-invariance}
\not\Rightarrow
\text{theory-native admissibility}.
\]

The admissible condition is:

\[
\boxed{
\text{unit-invariance}
+
\text{RCI recovery}.
}
\]

## 9) Proof Of Necessity

Assume a smooth operation is admitted before RCI recovery:

\[
\operatorname{Use}^{\Phi}_O(Y_1,\dots,Y_n)\downarrow
\]

but

\[
\neg\operatorname{RCIAdm}_O(Y_j;R_j)
\]

for some \(j\).

Then the operation uses \(Y_j\) as a smooth magnitude while the source package

\[
\operatorname{RCI}_O(R_j)
=
\left(
\operatorname{Idx}_O(R_j),
\operatorname{Rec}_O(R_j)
\right)
\]

is not recoverable.

Therefore the operation treats \(Y_j\) as if it were a primitive scalar.

But `GATE_009_001` denies scalar-as-primitive rendering, and `DEF_009_002` requires

\[
\operatorname{Recover}_O
\left(
Y_j,
\operatorname{Rec}_O(R_j)
\right)
=
\operatorname{RCI}_O(R_j).
\]

Contradiction.

Therefore:

\[
\boxed{
\operatorname{Use}^{\Phi}_O(Y_1,\dots,Y_n)\downarrow
\Rightarrow
\bigwedge_{i=1}^n
\operatorname{RCIAdm}_O(Y_i;R_i)\downarrow.
}
\]

Now assume a rescaling is admitted while changing the source package:

\[
\operatorname{RCI}_O(R)
\mapsto
\operatorname{RCI}'_O(R)
\neq
\operatorname{RCI}_O(R).
\]

Then the operation changes the recoverable count-index content while claiming to be a scale/report transform.

But by `THM_014_004`, a lawful report rescaling changes only the report coefficient and preserves the bridge-side content and construction record:

\[
q'u'=qu,
\qquad
\operatorname{Rec}_O(R)\ \text{unchanged}.
\]

Contradiction.

Therefore a lawful rescaling must satisfy

\[
\boxed{
\operatorname{RCI}'_O(R)
=
\operatorname{RCI}_O(R).
}
\]

## 10) Consequence

Smooth magnitudes may be used only after recovery:

\[
\boxed{
\text{smooth comparison / scaling admissible}
\Rightarrow
\text{source count indexes recoverable}.
}
\]

Equivalently:

\[
\boxed{
\text{No RCI}
\Rightarrow
\text{no lawful smooth-magnitude algebra}.
}
\]

This is the paper-level rule:

\[
\boxed{
\text{Scaling magnitudes can only be used if count indexes can be recovered.}
}
\]

## 11) Scope

This gate does not compute:

\[
A^\#_{\Psi,O},
\qquad
A^\#_{\Lambda,O},
\qquad
|\Psi|,
\qquad
|\Lambda|,
\qquad
\text{SI mass},
\qquad
\text{SI energy}.
\]

It does not define a new aperture function.

It does not derive SI units.

It does not block rendering.

It only says:

\[
\text{render first through the proper route, recover RCI, then compare or rescale}.
\]

## 12) Forward Use

Later cards may cite this gate when they use smooth magnitudes in any comparison, ratio, normalization, common rescaling, or dimensionless shape operation.

They must show:

\[
\forall i,\quad
\operatorname{RCIAdm}_O(Y_i;R_i)\downarrow,
\]

and

\[
\operatorname{Recover}^{\Phi}_O
\left(
\Phi(Y_1,\dots,Y_n),
\operatorname{OpRec}_O(\Phi;Y_1,\dots,Y_n)
\right)
=
\left(
\operatorname{RCI}_O(R_1),
\dots,
\operatorname{RCI}_O(R_n)
\right).
\]

If they cannot show that, the comparison or rescaling is inadmissible.
