# Unit Gauge Cancellation In Koide Shape — the Koide shape functional over three positive same-kind recovered reports is invariant under common observer-scale unit rescaling. If u' = λu, then q_i' = λ^{-1}q_i for every input, and the Koide shape value is unchanged. Therefore the kilogram / SI scale is not the content of the relation. Unit cancellation is necessary algebra, but admissible use still requires recovery of the full RCI tuple by GATE_009_003.

## 0) Governance & Scope Lock

This lemma proves only:

\[
\boxed{
\text{common observer-scale unit choice cancels out of the Koide shape.}
}
\]

It does not prove a target value.

It does not use measured numerical inputs.

It does not derive kilograms, seconds, joules, SI mass, or any individual smooth magnitude.

The admissible content is not the unit scale. The admissible content is:

\[
\boxed{
\text{unit-invariant shape}
+
\text{recoverable source RCI tuple}.
}
\]

## 1) Plain language

If three same-kind positive reports are all expressed in kilograms, grams, or any other common unit, the Koide shape gives the same dimensionless number. Changing the common unit rescales every reported coefficient by the same factor. The numerator and denominator both pick up the same factor, so it cancels.

That proves the kilogram scale is not what the relation is measuring.

But this does not make the dimensionless number primitive. By `GATE_009_003`, the shape may be used only if the three originating recoverable count-index packages remain recoverable after the operation.

## 2) Rendered Inputs

Let

\[
R_1,\ R_2,\ R_3
\]

be three promoted observer-local readout sources.

Let their rendered reports in a common admitted unit standard \(u\) be

\[
Y_i
=
q_{i,u}(R_i),
\qquad
i=1,2,3,
\]

with

\[
q_{i,u}(R_i)\in \mathbb R_{>0}.
\]

The shared standard condition is:

\[
\operatorname{Unit}_L(u)
\wedge
\bigwedge_{i=1}^{3}
\operatorname{Cmp}_L(Y_i,u).
\]

The recovery condition for each input is:

\[
\operatorname{RCIAdm}_O(Y_i;R_i)\downarrow
\iff
\operatorname{Recover}_O
\left(
Y_i,
\operatorname{Rec}_O(R_i)
\right)
=
\operatorname{RCI}_O(R_i).
\]

## 3) Koide Shape Functional

Define the card-local Koide shape functional over three positive report coefficients:

\[
\boxed{
\mathcal Q_K(q_1,q_2,q_3)
:=
\frac{
q_1+q_2+q_3
}{
\left(
\sqrt{q_1}+\sqrt{q_2}+\sqrt{q_3}
\right)^2
}
}
\]

where

\[
q_i>0.
\]

This is a dimensionless smooth shape operation on report coefficients, not an internal primitive scalar.

Let

\[
\Phi_K(Y_1,Y_2,Y_3)
:=
\mathcal Q_K
\left(
q_{1,u}(R_1),
q_{2,u}(R_2),
q_{3,u}(R_3)
\right).
\]

Write the operation result as

\[
Z_K=\Phi_K(Y_1,Y_2,Y_3).
\]

## 4) Common Unit Rescaling

By `THM_014_004`, a lawful common unit rescaling has the form

\[
u'=\lambda u,
\qquad
\lambda>0,
\]

and therefore

\[
q_{i,u'}(R_i)
=
\lambda^{-1}q_{i,u}(R_i)
\qquad
(i=1,2,3).
\]

So

\[
\mathcal Q_K(q_{1,u'},q_{2,u'},q_{3,u'})
=
\frac{
\lambda^{-1}q_{1,u}
+\lambda^{-1}q_{2,u}
+\lambda^{-1}q_{3,u}
}{
\left(
\sqrt{\lambda^{-1}q_{1,u}}
+
\sqrt{\lambda^{-1}q_{2,u}}
+
\sqrt{\lambda^{-1}q_{3,u}}
\right)^2
}.
\]

Since \(\lambda>0\),

\[
\sqrt{\lambda^{-1}q_{i,u}}
=
\lambda^{-1/2}\sqrt{q_{i,u}}.
\]

Thus the denominator becomes

\[
\left(
\lambda^{-1/2}
\left(
\sqrt{q_{1,u}}+\sqrt{q_{2,u}}+\sqrt{q_{3,u}}
\right)
\right)^2
=
\lambda^{-1}
\left(
\sqrt{q_{1,u}}+\sqrt{q_{2,u}}+\sqrt{q_{3,u}}
\right)^2.
\]

Therefore

\[
\mathcal Q_K(q_{1,u'},q_{2,u'},q_{3,u'})
=
\frac{
\lambda^{-1}(q_{1,u}+q_{2,u}+q_{3,u})
}{
\lambda^{-1}
\left(
\sqrt{q_{1,u}}+\sqrt{q_{2,u}}+\sqrt{q_{3,u}}
\right)^2
}.
\]

Canceling the common positive factor:

\[
\boxed{
\mathcal Q_K(q_{1,u'},q_{2,u'},q_{3,u'})
=
\mathcal Q_K(q_{1,u},q_{2,u},q_{3,u}).
}
\]

## 5) Unit Gauge Orbit

Define the common unit-gauge action

\[
g_\lambda:
(q_1,q_2,q_3;u)
\mapsto
(\lambda^{-1}q_1,\lambda^{-1}q_2,\lambda^{-1}q_3;\lambda u).
\]

Then

\[
\boxed{
\mathcal Q_K(g_\lambda(q_1,q_2,q_3;u))
=
\mathcal Q_K(q_1,q_2,q_3;u)
}
\]

for all

\[
\lambda>0.
\]

So \(\mathcal Q_K\) factors through the equivalence class

\[
(q_1,q_2,q_3;u)
\sim
(\lambda^{-1}q_1,\lambda^{-1}q_2,\lambda^{-1}q_3;\lambda u).
\]

The selected unit representative is not determined by the shape value.

## 6) Kilogram Scale Is Not The Content

If the common report standard is written as a kilogram standard,

\[
u=\mathrm{kg},
\]

then a different admitted kilogram-scale representative has the form

\[
u_\lambda=\lambda\,\mathrm{kg}.
\]

The coefficients transform as

\[
q_{i,u_\lambda}
=
\lambda^{-1}q_{i,\mathrm{kg}}.
\]

But by §4,

\[
\boxed{
\mathcal Q_K
(q_{1,u_\lambda},q_{2,u_\lambda},q_{3,u_\lambda})
=
\mathcal Q_K
(q_{1,\mathrm{kg}},q_{2,\mathrm{kg}},q_{3,\mathrm{kg}}).
}
\]

Therefore:

\[
\boxed{
\mathcal Q_K
\text{ does not recover the kilogram scale.}
}
\]

Equivalently, no map from the shape value alone can select the unit representative:

\[
\boxed{
\mathcal Q_K(q_1,q_2,q_3)=z
\not\Rightarrow
u=\mathrm{kg}.
}
\]

The kilogram scale is a reporting convention, not the content of the relation.

## 7) Recovery Still Required

Unit cancellation alone is not admissibility.

By `GATE_009_003`, the operation

\[
\operatorname{Use}^{\Phi_K}_O(Y_1,Y_2,Y_3)
\]

is admissible only if

\[
\bigwedge_{i=1}^{3}
\operatorname{RCIAdm}_O(Y_i;R_i)\downarrow
\]

and there exists an operation-level recovery map such that

\[
\boxed{
\operatorname{Recover}^{\Phi_K}_O
\left(
Z_K,
\operatorname{OpRec}_O(\Phi_K;Y_1,Y_2,Y_3)
\right)
=
\left(
\operatorname{RCI}_O(R_1),
\operatorname{RCI}_O(R_2),
\operatorname{RCI}_O(R_3)
\right).
}
\]

Thus:

\[
\boxed{
\text{unit cancellation}
\not\Rightarrow
\text{admissible comparison}.
}
\]

The admissible condition is:

\[
\boxed{
\text{unit cancellation}
+
\text{full RCI-tuple recovery}.
}
\]

## 8) Non-Common Scaling Is Not Unit Gauge

The cancellation above requires one common unit rescaling.

If the inputs are rescaled independently,

\[
(q_1,q_2,q_3)
\mapsto
(\alpha_1q_1,\alpha_2q_2,\alpha_3q_3),
\]

with not all \(\alpha_i\) equal, then the Koide shape is not invariant in general.

Exact counterexample:

\[
\mathcal Q_K(1,1,1)
=
\frac{3}{(1+1+1)^2}
=
\frac13.
\]

But

\[
\mathcal Q_K(4,1,1)
=
\frac{6}{(2+1+1)^2}
=
\frac{6}{16}
=
\frac38.
\]

Since

\[
\frac38\neq\frac13,
\]

independent input rescaling is not a lawful unit-gauge cancellation.

## 9) Result

This lemma establishes:

\[
\boxed{
u'=\lambda u
\Rightarrow
\mathcal Q_K(q_{1,u'},q_{2,u'},q_{3,u'})
=
\mathcal Q_K(q_{1,u},q_{2,u},q_{3,u}).
}
\]

It also establishes:

\[
\boxed{
\mathcal Q_K
\text{ is blind to the common SI / kilogram scale.}
}
\]

It does not establish:

\[
\mathcal Q_K=\frac23.
\]

It does not establish any measured-sector interpretation.

It does not establish any individual magnitude.

It does not replace RCI recovery.

## 10) Witness Spec

The witness verifies symbolically:

\[
\mathcal Q_K(\lambda^{-1}q_1,\lambda^{-1}q_2,\lambda^{-1}q_3)-\mathcal Q_K(q_1,q_2,q_3)=0
\]

under assumptions

\[
q_1,q_2,q_3,\lambda>0,
\]

and the non-common scaling counterexample

\[
\mathcal Q_K(1,1,1)=\frac13,
\qquad
\mathcal Q_K(4,1,1)=\frac38
\quad(\neq \tfrac13),
\]

and that no target value (in particular \(\tfrac23\)) is asserted. Structural checks require the `GATE_009_003` operation recovery of the full RCI tuple:

\[
\operatorname{Use}^{\Phi_K}_O(Y_1,Y_2,Y_3)\downarrow
\Rightarrow
\bigwedge_i \operatorname{RCIAdm}_O(Y_i;R_i)\downarrow,
\qquad
\operatorname{Recover}^{\Phi_K}_O
(Z_K,\operatorname{OpRec}_O)
=
(\operatorname{RCI}_O(R_i))_{i=1}^3.
\]

Corrupt modes independently break: (1) common-unit cancellation, (2) the square-root scaling exponent, (3) the non-common-scaling rejection, (4) the RCI-tuple requirement, (5) the no-target-value scope lock, (6) the no-SI-derivation scope lock, (7) zero/negative input admission.
