# Recoverable Count Index — reusable notation for recorded-construction recovery. Defines the recoverable count-index package RCI_O(R) carried by an observer-local readout R: the finite originating count-index data Idx_O(R) together with the promoted construction record Rec_O(R). A rendered scalar / aperture value / SI report Y of R is admissible only when recovery from (Y, Rec_O(R)) returns the same package. This promotes the GATE_009_001 recovery object into reusable notation without computing any scalar, SI value, A#, |Ψ|, |Λ|, or physical magnitude.

## 0) Governance & Scope Lock

This card defines reusable notation for the recovery object already required by `GATE_009_001`.

It does not compute a rendered value.

It does not compute

\[
A^\#,\qquad |\Psi|,\qquad |\Lambda|,
\]

and it does not derive any SI unit.

It defines the object that must survive rendering:

\[
\boxed{
\text{recoverable count index}
=
\text{originating count-index data}
+
\text{construction record}.
}
\]

## 1) Plain language

`GATE_009_001` already requires that whenever you render a readout as a smooth scalar / aperture value / SI number, the originating **count** must stay recoverable — not from the number alone, but from the number **together with** the promoted construction record. That requirement was stated with card-local notation inside the gate. This card gives that recovery object a **reusable name** so later cards can cite it instead of re-deriving it each time: the *recoverable count index* `RCI_O(R)` is the pair of (a) the finite count-index data `Idx_O(R)` that made the readout possible, and (b) the construction record `Rec_O(R)`. For the Ψ support readout the index data is the pair of cardinalities `(4,3)` (the four-cell occupancy carrier and its three-cell denominator); for the Λ/G count readout it is the record-domain count `9`. A rendered value is admissible only if recovering from it (with the record) returns this same package — so a bare scalar can never be promoted into a primitive fact. The card computes no magnitude, no `A#`, and no SI value; it only names the recovery condition.

## 2) Definition

Let \(R\) be a promoted observer-local readout object.

Let

\[
\operatorname{Rec}_O(R)
\]

be the promoted construction record cited for \(R\).

Let

\[
\pi_{\mathrm{idx}}
\]

be the card-local projection that extracts from the construction record the finite count-index data that made the readout possible.

Define

\[
\boxed{
\operatorname{Idx}_O(R)
:=
\pi_{\mathrm{idx}}\!\left(\operatorname{Rec}_O(R)\right)
}
\]

and define the recoverable count-index package

\[
\boxed{
\operatorname{RCI}_O(R)
:=
\left(
\operatorname{Idx}_O(R),
\operatorname{Rec}_O(R)
\right).
}
\]

This is not a scalar and not a physical magnitude. It is a typed recovery package.

## 3) Rendered-Value Admissibility

Let \(Y\) be a rendered presentation of \(R\):

\[
Y=\operatorname{Render}_O(R;\mathcal A),
\]

where \(\mathcal A\) denotes the rendering / aperture / scalar / report context.

Then \(Y\) is count-index admissible exactly when there exists a recovery map

\[
\operatorname{Recover}_O
\]

such that

\[
\boxed{
\operatorname{Recover}_O
\left(
Y,
\operatorname{Rec}_O(R)
\right)
=
\operatorname{RCI}_O(R)
}
\]

or, equivalently,

\[
\operatorname{Recover}_O
\left(
Y,
\operatorname{Rec}_O(R)
\right)
=
\left(
\operatorname{Idx}_O(R),
\operatorname{Rec}_O(R)
\right).
\]

Projection form:

\[
\pi_1
\operatorname{Recover}_O
\left(
Y,
\operatorname{Rec}_O(R)
\right)
=
\operatorname{Idx}_O(R),
\]

\[
\pi_2
\operatorname{Recover}_O
\left(
Y,
\operatorname{Rec}_O(R)
\right)
=
\operatorname{Rec}_O(R).
\]

So recovery must preserve both:

\[
\text{count-index data}
\quad\text{and}\quad
\text{construction record}.
\]

## 4) Scalar-Only Recovery Is Insufficient

A bare rendered scalar may not replace the record.

The condition

\[
\exists f\,
\big(
f(Y)=\operatorname{Idx}_O(R)
\big)
\]

does not by itself satisfy recoverability.

The admissible condition is the two-input recorded-construction condition:

\[
\operatorname{Recover}_O
\left(
Y,
\operatorname{Rec}_O(R)
\right)
=
\operatorname{RCI}_O(R).
\]

Thus

\[
\operatorname{Recover}_O(Y)
=
\operatorname{Idx}_O(R)
\]

is not an admissibility certificate unless the promoted construction record is also carried.

## 6) Compatibility With SI Reports

By `THM_014_004`, an SI report is an observer-scale report of bridge-side content, not a primitive.

Let

\[
Y=\operatorname{Rep}^{K}_{u,O}(R)
\]

be a bridge-side report of \(R\) in an admitted unit / standard \(u\).

Then the report is recoverability-admissible only if

\[
\operatorname{Recover}_O
\left(
\operatorname{Rep}^{K}_{u,O}(R),
\operatorname{Rec}_O(R)
\right)
=
\operatorname{RCI}_O(R).
\]

If the unit is rescaled,

\[
u'=\lambda u,
\qquad
\lambda>0,
\]

then `THM_014_004` gives the same bridge-side content under the changed report coefficient. The recoverable count-index package must remain invariant:

\[
\boxed{
\operatorname{RCI}_O
\left(
\operatorname{Rep}^{K}_{u',O}(R);R
\right)
=
\operatorname{RCI}_O
\left(
\operatorname{Rep}^{K}_{u,O}(R);R
\right)
=
\operatorname{RCI}_O(R).
}
\]

Thus changing reporting units may change the displayed scalar, but it may not change the recoverable count-index package.

## 7) Consequence

A rendered scalar is admissible only as a presentation of a recoverable index package:

\[
\boxed{
Y\ \text{admissible as a rendering of }R
\Rightarrow
\exists \operatorname{Recover}_O:
\operatorname{Recover}_O(Y,\operatorname{Rec}_O(R))
=
\operatorname{RCI}_O(R).
}
\]

Equivalently,

\[
Y\ \text{admissible}
\Rightarrow
\operatorname{Idx}_O(R)
\ \text{and}\
\operatorname{Rec}_O(R)
\ \text{are recoverable}.
\]

Therefore a scalar cannot be promoted into a primitive:

\[
Y
\neq
\text{primitive object}.
\]

It is only a rendered presentation of

\[
\operatorname{RCI}_O(R).
\]

## 8) Scope

This card defines reusable notation:

\[
\operatorname{Idx}_O(R),
\qquad
\operatorname{RCI}_O(R),
\qquad
\operatorname{Recover}_O(Y,\operatorname{Rec}_O(R)).
\]

It does not compute

\[
A^\#_{\Psi,O},
\quad
A^\#_{\Lambda,O},
\quad
|\Psi|,
\quad
|\Lambda|,
\quad
\text{SI mass},
\quad
\text{SI energy}.
\]

It does not identify

\[
N_{\Lambda,O}=9
\]

with

\[
\operatorname{Cap}=9.
\]

It only records the reusable recovery condition required for a rendered value to be admissible as a presentation of \(\operatorname{RCI}_O(R)\) — the recovery package later cards (the recovery-before-scaling gate) cite, with no magnitude, `A#`, or SI value computed here.
