## 1) Plain language

Two clocks, one heartbeat. The substrate has a **tick**: every time a unit-account completes, the
escapement is forced to post exactly one unit (ΔI = 1) — that is a tick event. The phase has a
**closure**: every time the relational phase completes one full 2π turn, one whole unit of
distinguishability has closed — that is a closure event. This card proves the simple, load-bearing
thing the junction needs next: **those are the same heartbeat counted twice.** Each completed
unit-account is one completed 2π closure, and each completed 2π closure is one completed unit-account —
so the ticks and the closures pair up **one for one**, with none left over on either side.

That pairing is the map `tick_closure_map`, and it is a **bijection**: one tick ↔ one closure. The proof
is short because the pieces are already promoted: the escapement forces exactly one tick per completion
(it cannot post zero or two), the phase gives exactly one closure per completed unit, and we already
recorded that each completed unit-account **is** one 2π closure. Put together: every completion has
exactly one of each, so the pairing is one-to-one and onto.

It is an honest, **falsifiable** claim — it can lose. If the books ever showed a completed tick with no
matching closure (or a closure with no tick), the bijection would be broken and this theorem would fail.
We claim the promoted machinery forbids that mismatch; a counterexample would refute us.

Three careful limits. The orientation σ rides **alongside** — an oriented tick maps to the oriented
closure of the **same** σ; σ is never dropped and never read back out of the smooth phase (we proved the
phase alone loses σ). The closure events are a **discrete count** of completed turns, not a continuous
phase — there is no phase-as-a-function-of-time here. And this card stops at the **correspondence**: it
sets up the next card (the rate equality, OB-B) but does **not** claim the rates are equal, and says
nothing about the conjecture, physical time, or any observer.

## 4) Proof (the tick↔closure bijection)

**Step 1 — exactly one tick per completed unit-account (THM_005_009 / THM_006_007).** At unit completion
of a unit-account, the escapement is FORCED to post exactly one unit: ΔI = 1 FOLLOWS (THM_005_009;
re-grounded at the aperture layer, THM_006_007 — integrality forced, never declared; "no tick this
cycle" is the absence-of-posting predicate, never ΔI = 0). So each completed unit-account yields
**exactly one** tick event {k : Δ_k = 1} — not zero, not two.

**Step 2 — exactly one closure per completed unit (ROLEDEF_006_008).** ROLEDEF_006_008 types each completed 2π
closure as **one completed unit of distinguishability**; the closure count is I = ⌊|g_Φ|⌋ (the number of
completed 2π closures), one per completed unit (ℤ≥1 for ≥1 closure; the sub-unit/no-closure case the
record-absent predicate). So each completed unit yields **exactly one** closure event {n}.

**Step 3 — the correspondence anchor (DEF_007_001).** DEF_007_001 states the load-bearing S06
correspondence: **each completed unit-account is one 2π closure.** Both Step 1's tick and Step 2's closure
are readings of the **same** completion — one completed unit of distinguishability (I = 1, P1): the
substrate-side reading (the forced ΔI = 1 posting) and the phase-side reading (the 2π closure). There is
no second, independent completion count (P1: existence counted in completed units of I = 1; the tick and
the closure both count completed units).

**Step 4 — tick_closure_map is a bijection.** Define tick_closure_map by mapping the tick of each
completed unit-account to the 2π closure of that same completion. By Steps 1–3:
- **Injective:** distinct completed unit-accounts give distinct ticks (Step 1) and distinct closures
  (Step 2); tick_closure_map carries distinct ticks to distinct closures.
- **Surjective:** every closure event is a completed 2π closure (Step 2) = a completed unit-account
  (Step 3) = a tick event (Step 1); so every closure has its tick.
Hence tick_closure_map is a **bijection** — one tick ↔ one closure. ∎

**(Can-fail, P0 — the risky claim.)** The bijection is **falsifiable**: were there a completed tick with
no completed closure (Step 1 without Step 2 for some completion), or a completed closure with no tick
(Step 2 without Step 1), tick_closure_map would fail injectivity or surjectivity. The promoted machinery
**forbids** the mismatch (each completion forces exactly one tick AND one closure, both anchored on the
unit), but a counterexample within the licensed machinery would refute the theorem (F-S06tc-1).

**(σ carried, not recovered — THM_007_005 / RC-2.)** Each completion's tick and closure carry the SAME
orientation σ (THM_007_005: σ is the orientation of the closure = the side of the paired posting — one σ
per completion). tick_closure_map maps the oriented tick to the oriented closure of the same σ — σ rides
through, **never erased**. σ is **not** recovered from the continuous phase: φ_rel = 2π·|g_Φ| (mod 2π) is
magnitude-only, so the same-magnitude-opposite-orientation pair shares φ_rel but differs in σ — the phase
cannot determine σ (the held THM_S06_003 diagnostic; RC-2).

**(Scope — sets up OB-B, does not assert it.)** tick_closure_map is the **event** bijection (one tick ↔
one closure per completion). It does **NOT** assert the **rate** equality — that lim N_tick/x = Ω equals
the resolved phase-closure rate per update (OB-B, the calibrated rate/density identity), nor the
conjecture (LAST). It establishes the correspondence OB-B's rate equality rides on, and stops there. The
Ω rate is named comparison-only (the squeeze/lattice-π are not the foundation of the event bijection — it
is forced by the per-completion correspondence, not by a rate).
