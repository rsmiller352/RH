# Cancellativity of the quantity cone — DERIVED (the comparability route: positivity + totality force cancellation)

## 0) Governance & Scope Lock

associativity/positivity, (A2) the split cone order, (A4) same-tag comparability — and

## 1) Plain language

If adding the same amount to two holdings gives equal results, the holdings were equal to
begin with. The old stack had to ASSUME this (AX_S01_006), because the cone's other
properties genuinely do not imply it — there is a concrete algebra that satisfies all of
them and still collapses two different holdings into one sum. But that algebra has a
tell: it contains pairs of same-kind amounts where neither is "at least" the other — two
amounts of one kind that cannot be compared at all. Once the definition of a quantity
cone says what everyone already meant by "amounts of one kind" — any two of them compare
(DEF_002_001 (A4)) — cancellation stops being an assumption and becomes a three-step
proof: if the two holdings differed, one would strictly exceed the other by some gap d,
and adding the same amount to both would preserve that gap — making a sum strictly
exceed ITSELF by d, which positivity forbids. Nothing exceeds itself; so the holdings
were equal.

## 2) Statement

**Premises** (all from DEF_002_001 as amended 2026-07-11):

- **(A1)** (𝒟+, +) is a commutative semigroup (closure, commutativity, associativity)
  satisfying the positivity axiom ∀x, y ∈ 𝒟+: x + y ≠ x.
- **(A2)** The cone order, split form: a ⪰ b :⟺ a = b ∨ (∃d ∈ 𝒟+: b + d = a), with the
  strict part a ≻ b :⟺ ∃d ∈ 𝒟+: b + d = a; the disjuncts mutually exclusive by
  positivity.
- **(A4)** Comparability of like quantities: for all a, b ∈ 𝒟+ of one type tag,
  a ⪰ b ∨ b ⪰ a.

**Claim (cancellativity).** For all a, b, q ∈ 𝒟+ (same type tag):

$$a + q = b + q \;\Longrightarrow\; a = b.$$

**Immediate consequence (witness uniqueness — the content DEF_002_004 (B3) and
THM_002_012 consume, unchanged in statement from the superseded AX_S01_006 §2):** the
witness d in the strict order b + d = a is unique when it exists (restricted subtraction
is well-posed existentially). Proof at §4, Corollary.

## 4) Derivation (THM obligation — complete proof)

**Theorem.** Under (A1), (A2), (A4): a + q = b + q ⟹ a = b.

**Proof.**

- **Step 1 (hypothesis and case split).** Suppose a + q = b + q and, for contradiction,
  a ≠ b. By (A4) the same-tag pair (a, b) is comparable: a ⪰ b or b ⪰ a. In either
  disjunct, the equality case is excluded by a ≠ b, so one STRICT comparison holds. The
  two strict cases are mirror images under exchanging the names a ↔ b, and the
  hypothesis a + q = b + q is symmetric in a, b (equality is symmetric; no orientation
  is consumed) — so it suffices to treat a ≻ b. [The "wlog" is name-exchange on a
  symmetric hypothesis, not a hidden orientation choice — no signed object enters.]

- **Step 2 (unfold the strict order).** a ≻ b gives, by (A2), a witness d ∈ 𝒟+ with
  $$b + d = a.$$

- **Step 3 (substitute into the hypothesis).** Using commutativity and associativity
  (A1):
  $$b + q \;=\; a + q \;=\; (b + d) + q \;=\; (b + q) + d.$$

- **Step 4 (positivity refutes).** Set x := b + q ∈ 𝒟+ (closure, A1) and y := d ∈ 𝒟+.
  Step 3 reads x + y = x — contradicting the positivity axiom (A1: ∀x, y: x + y ≠ x).

- **Step 5 (conclude).** The supposition a ≠ b is impossible; hence a = b. $\blacksquare$

**Corollary (witness uniqueness).** If b + d = a and b + d′ = a with d, d′ ∈ 𝒟+, then
b + d = b + d′, i.e. d + b = d′ + b (commutativity), and the Theorem (at the triple
(d, d′, b)) gives d = d′. $\blacksquare$

**Where each premise is load-bearing (the honesty ledger of the proof):**
- (A4) is consumed EXACTLY ONCE, at Step 1 — it supplies the strict comparison a ≻ b
  from a ≠ b. Without it the proof has no first move; §9(i) shows the failure is real,
  not hypothetical (the countermodel).
- (A2) is consumed at Steps 1–2 (the split form and the strict witness).
- (A1) is consumed at Steps 3–4 (commutativity, associativity, closure, positivity).
- Nothing else is consumed. In particular NO downstream card, NO transfer relation, NO
  conservation, NO non-erasure lemma, and NOT AX_S01_006 (forbidden_inputs; the
  circularity fence holds by inspection of Steps 1–5).
