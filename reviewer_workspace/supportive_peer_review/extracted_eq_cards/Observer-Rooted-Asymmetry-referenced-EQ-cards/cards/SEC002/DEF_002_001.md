## 1) Plain language

Quantity in this framework never floats free: it is always somebody's holding in some
relationship. The book has registers (the relationships), and a register that appears in
the book holds a strictly positive amount — a register holding nothing is simply not in
the book (absence is a fact about the book, not a zero written in it). Amounts can be
combined (added) and compared (one amount is at least another if you can top the smaller
up to the larger, or they are equal) — and that is all. There is no subtraction, no
negative, and no zero amount, because the framework moves quantity around (next card)
instead of negating or zeroing it. [Plain language re-walked 2026-06-12 with the D-046
amendment — prior wording ("each register holds a nonnegative amount… nothing below
zero") superseded.]

## 2) Statement

1. **Registers.** R is a finite set of relationship registers.
2. **Quantity cone.** [SUPERSEDED 2026-06-12 — replaced by clauses (A1)+(A2) of the dated
   amendment block at the end of this section (D-043/D-046); prior text preserved:]
   𝒟≥0 is a commutative monoid (𝒟≥0, +, 0_𝒟) that is
   **zerosumfree**: a + b = 0_𝒟 ⟹ a = b = 0_𝒟 (no element has an additive inverse
   except 0_𝒟 — this is what makes it a cone), equipped with the **cone order**
   $$a \succeq b \;:\Longleftrightarrow\; \exists\, d \in \mathcal{D}_{\ge 0}:\; b + d = a.$$
3. **Type tags (TD-009).** Every element of 𝒟+ carries the quantity-type tag of
   its register family; + and ⪰ are defined only within a tag; cross-tag combinations are
   undefined (not zero, not error-recovered — undefined). [Amended 2026-06-12: carrier
   renamed 𝒟+ (was 𝒟≥0); clause otherwise unchanged.]
4. **Holdings.** [SUPERSEDED 2026-06-12 — replaced by clause (A3) of the dated amendment
   block below (D-043/D-046); prior text preserved:] A holdings state is a map
   h : R → 𝒟≥0 (tag-respecting). The value
   h(r) = 0_𝒟 is admissible (absence-marker — licensed formal role, IMPORT_001_007 §2).

**[Amendment 2026-06-12 — D-043 typed-predicate strengthening (RSM directive), applied
through the Phase-C gauntlet]:** The quantity algebra and the holdings typing are
re-typed; no zero object exists internally.

**(A1) Quantity semigroup.** $\mathcal{D}_{+}$ is a commutative **semigroup**
$(\mathcal{D}_{+}, +)$ — **no identity element in the signature** — satisfying the
**semigroup-positivity axiom**
$$\forall\, x, y \in \mathcal{D}_{+}:\quad x + y \neq x.$$
Closure is the signature ($+ : \mathcal{D}_{+} \times \mathcal{D}_{+} \to
\mathcal{D}_{+}$). Zerosumfreeness is not statable in this signature (its statement
mentions $0_{\mathcal{D}}$) and is not needed: its closure half is definitional here,
and no inverse is statable without an identity. The positivity axiom is the added
clause (§1.4 below records exactly why it must be stated).

**(A2) Cone order, SPLIT explicitly (equal-or-strictly-more):**
$$a \succeq b \;:\Longleftrightarrow\; a = b \;\lor\; \big(\exists\, d \in
\mathcal{D}_{+}:\; b + d = a\big),$$
with the strict part $a \succ b :\Longleftrightarrow \exists\, d \in \mathcal{D}_{+}:
b + d = a$. By positivity the two disjuncts are mutually exclusive ($b + d = a = b$
would give $b + d = b$).

**(A3) Holdings are PARTIAL maps.** A holdings state is a pair
$(\operatorname{supp}(h), h)$ with $\operatorname{supp}(h) \subseteq R$ finite and
$h : \operatorname{supp}(h) \to \mathcal{D}_{+}$ (tag-respecting); every held value is
strictly positive by type. **"Empty register" $:=$ $r \notin \operatorname{supp}(h)$**
— the **register-absence predicate** $\mathrm{absent}_h(r)$ (the record-absent typed
predicate instantiated at holdings; GUARD_001_008). Absence is never a held value;
no $h(r) = 0_{\mathcal{D}}$ exists.

Superseded clause, quoted: "The value h(r) = 0_𝒟 is admissible (absence-marker —
licensed formal role, IMPORT_001_007 §2)" — absence is now the typed predicate above;
the IMPORT_001_007 licensed-roles clause narrows accordingly (cross-note, §5.3 of the
proposal report).

**[Amendment 2026-07-11 — root-reduction (RSM directive: land the stack on a single
physical axiom); **pending-the-gauntlet**]:** one clause is added to the quantity-cone
signature.

**(A4) Comparability of like quantities (totality of the cone order).** For all
$a, b \in \mathcal{D}_{+}$ carrying one type tag:
$$a \succeq b \;\lor\; b \succeq a.$$
Magnitudes of one kind are pairwise comparable — the classical (Eudoxan) mark of
same-kind magnitude, on the same discrete-substrate ground this card's lineage already
stands on (Euclid Book VII unit/number — lineage row 3; comparability of like magnitudes
is Book V's companion discipline). The clause is DEFINITIONAL: it says what counts as a
quantity cone of one kind, exactly as commutativity and positivity (A1) already do; it
asserts nothing about existence and is not a physical axiom. It narrows the definition
class (a structure whose same-tag cone order is merely partial is not a quantity cone of
this framework); the exhibited model satisfies it (§4). **Consequence:** cancellativity
of + is now DERIVABLE from (A1)+(A2)+(A4) — THM_002_003 — and the F-153a cancellativity
axiom (AX_S01_006) demotes to a derived statement (supersession recorded on that card).
The F-153a obligation ("stated, never inherited from ℕ-intuition") remains discharged:
comparability is STATED here, and cancellativity is PROVED from it.

  **Antisymmetry proof:** Suppose $a \succeq b$ and $b \succeq a$. If either holds by the
  equality disjunct,
  $a = b$. Otherwise both are strict: $b + d = a$ and $a + d' = b$ with
  $d, d' \in \mathcal{D}_{+}$; substituting, $a + (d' + d) = a$ with
  $d' + d \in \mathcal{D}_{+}$ (closure) — contradicting the positivity axiom
  ($x + y \neq x$ at $x = a$, $y = d' + d$). So the strict-strict case is impossible and
  $a = b$. $\blacksquare$

  [Superseded prior text, quoted: "⪰ is reflexive (witness d = 0_𝒟) and transitive
