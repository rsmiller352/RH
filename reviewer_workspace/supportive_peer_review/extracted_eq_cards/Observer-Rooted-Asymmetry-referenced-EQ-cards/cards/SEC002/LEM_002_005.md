# Ledger conservation — transfers move quantity, never create or destroy it

## 0) Governance & Scope Lock

Proved subsidiary claim; complete proof on the card. Exact symbolic forms only. The proof
may use only DEF_002_004's defining clauses and the monoid laws of DEF_002_001 (via
DEF_002_004). No physical language.

## 1) Plain language

Moving an apple from Alice to Bob changes who holds it, never how many apples there are.
The book's total — register by register type — is untouched by any transfer, and therefore
by any finite sequence of transfers. Quantity moves; it is never created or destroyed by
movement.

## 2) Statement

[Amended 2026-06-12, D-043/D-046 — statement re-typed for partial holdings:] For every
holdings state (supp(h), h) and every admissible
transfer T(A→B; q) with post-state h′ (tag-wise, per type tag):

$$\sum_{r \in \operatorname{supp}(h')} h'(r) \;=\; \sum_{r \in \operatorname{supp}(h)} h(r),$$

both supports nonempty (A ∈ supp(h) by admissibility; B ∈ supp(h′) by (B3)). Tags with
no holdings admit no transfer, and the no-holdings predicate is preserved trivially —
no empty sum is ever formed (there is no value for one to take).

**Corollary (finite compositions):** the tag-wise total is invariant under every finite
sequence of admissible transfers.

[Superseded statement, quoted: "For every holdings state h : R → 𝒟≥0 and every
admissible transfer T(A→B; q) with post-state h′ (tag-wise, per type tag):
Σ_{r ∈ R} h′(r) = Σ_{r ∈ R} h(r)."]

## 3) Input contract (GR-1)

Objects: h, h′, A, B, q as typed at DEF_002_004. Domains: tag-respecting holdings states

## 4) Proof (complete)

[Amended 2026-06-12, D-043/D-046 — affected lines rewritten to the four support cases;
the algebraic content is unchanged, the single display becomes a four-case display:]

Fix a type tag and write the tag's registers' holdings only (other tags' holdings are
untouched by the bystander clause of DEF_002_004 §2 (B3)). Bystander supports
coincide: supp(h) ∖ {A, B} = supp(h′) ∖ {A, B} ((B3) bystander clause,
present-or-absent alike), so the remainder term
$\Sigma_{\text{rest}} := \sum_{r \in \operatorname{supp}(h) \setminus \{A,B\}} h(r)$
**exists on both sides or on neither, with the same value**; equality reduces to the
A/B contributions. Writing [Σ_rest] for the term that is present iff the bystander
support is nonempty (identical on both sides; lines hold without it when absent):

1. B ∈ supp(h), h(A) ≻ q: Σh′ = h′(A) + (h(B) + q) + [Σ_rest]
   = (h′(A) + q) + h(B) + [Σ_rest] = h(A) + h(B) + [Σ_rest] = Σh.
2. B ∈ supp(h), h(A) = q (A leaves): Σh′ = (h(B) + q) + [Σ_rest]
   = h(B) + h(A) + [Σ_rest] = Σh.
3. B ∉ supp(h), h(A) ≻ q (B joins): Σh′ = h′(A) + q + [Σ_rest]
   = h(A) + [Σ_rest] = Σh.
4. B ∉ supp(h), h(A) = q (A leaves, B joins): Σh′ = q + [Σ_rest]
   = h(A) + [Σ_rest] = Σh.

Only associativity/commutativity are used, as before. The corollary follows by induction
over the sequence, each step one of the four cases; supports may grow and shrink along
the way, the tag-wise total never changes. ∎

Note: the proof consumes commutativity/associativity only; cancellativity (AX_S01_006)
enters solely through DEF_002_004's well-definedness of h′(A) (strict case), already
discharged there.

[Superseded proof display, quoted: "Let Σ denote the sum over r ∈ R. By the
defining clauses: h′(r) = h(r) for r ∉ {A, B}, h′(B) = h(B) + q, and h′(A) + q = h(A).
Then, using only associativity and commutativity of + in 𝒟≥0:
Σ h′ = h′(A) + h′(B) + Σ_{r ≠ A,B} h(r) = h′(A) + (h(B) + q) + Σ_{r ≠ A,B} h(r)
= (h′(A) + q) + h(B) + Σ_{r ≠ A,B} h(r) = h(A) + h(B) + Σ_{r ≠ A,B} h(r) = Σ h."]

## 5) Scope & non-overclaim

Conservation under TRANSFERS — exactly the operations DEF_002_004 licenses. Says nothing
about operations not yet defined (mergers, splits, future growth/creation cards must each
restate their own conservation or declare their deviation explicitly). No physical
conservation claim (pre-physical, P7). Guard references: GUARD_001_006.
