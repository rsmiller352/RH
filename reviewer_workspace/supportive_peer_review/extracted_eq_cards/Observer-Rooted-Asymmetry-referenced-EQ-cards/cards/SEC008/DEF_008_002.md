## 1) Plain language

S06 finished a closed internal record: a list of **completed** relational updates — each one a posted,
resolved completion (resolved meaning the action-gap reached a full unit; below that there is simply no
record). S07's job is to talk about what **reads** that record. This card takes the very first, smallest step:
it says **what the reader is**, and stops there.

The reader — call it a **locus** — is not a person and not a mind. It is a **relationship**: the relational
standpoint at a given **resolution scale** through which the already-completed distinctions show up *as
distinguishable for that standpoint*. Think of it as a vantage, defined purely by which already-resolved
completions are tellable-apart from where it stands. Nothing about it is psychological; it is bookkeeping
geometry. And — the seam this card must keep — **the locus does not make anything distinguishable**: the
distinctions were already resolved internally (that is the aperture's job, A_Φ; and being-distinguishable-at-
all is primitive, AX_001_001). The locus is only the **standpoint at which the already-resolved ones are
available**; it adds nothing, resolves nothing, and is not a second aperture.

What the locus gives you is a **collection** — the set of already-resolved completions that are
distinguishable at its scale, each still carrying its orientation tag. And the single most important thing
about this card is what that collection is **not**: it is **not a sequence**. There is no first, no next, no
before-or-after, no duration, no count that climbs, no clock. It is an **unordered** set — a *what-is-here*,
not a *what-comes-after-what*. Ordering is a later, separate job (clockhood); turning any of this into a clock
or a time is later still. This card refuses all of that on purpose: it names that the locus **registers** the
completions, but it does not say **how** registration works (also a later job), and it never reaches back to
change the finished internal record — it only reads from it.

So this is the bare doorway-object of the readout side: a scale-relative relational vantage whose content is
an unordered, orientation-tagged set of already-resolved completions. Everything that would make it tick — an
order, a measure, a clock, a physical time, an energy, a prediction — is deliberately left for the obligations
that come after.
