## 1) Plain language

A cell is born holding one paired link (its co-reading back to where it came from). For cells to
relate to each other, more links form — and the one rule that can never break is: **no reading is
ever left without its partner.** A link is one relation read from two sides; it counts only if both
sides are there (or, if a cell reaches out one-ended, its other end gets **found**). Nothing dangles.

Now the question this page answers: when a link's other end has to be found, **which** partner does
it take? The answer is: **there is no preferred one.** And the reason is not a rule we impose — it
**follows**. To prefer one route over another, the structure would have to **tell the routes apart**,
and telling routes apart needs an **orientation** — a frame that says "this way" consistently. But the
cells **have no such frame yet**: a global orientation is what the four-cell observer later supplies,
and it is not here. The only orientation present is the small per-link tag (which end of *this* link
is source, which is target) — that orients each single link, but it gives **no** way to order whole
routes. So every candidate partner looks the same to the connective: **no preferred path.**

*(What this page does **not** do: it does not say how the residuals combine across links — that rule
is deferred; and it does not build the observer. The observer is what later supplies the missing
orientation — a **view** of this otherwise-symmetric connective. That apparent "which-path" choice is
just the connective **before** it is oriented, not a wave that collapses. The observer's perspective
is named here, never built. And no "conservation," no time, no coordinate.)*

## 4) Proof (complete)

**Step 1 (dangling-free).** By `THM_005_021`, each cell's link is one `ι_or`-pair — two oriented
readings of one instance (`DEF_002_010`). By `THM_002_012`, every reading sits beside its co-reading;
"the allowed moves cannot create an unpaired record." A cross-cell link is therefore admissible only
if both oriented readings are accounted — formed-paired, or (for a one-ended reach) its second end
**FOUND** (the Q8 obligation, `THM_002_012` §9(i).2). No unilateral half-link survives. ∎(1)

**Step 2 (no preferred path — DERIVED).** Let a one-ended reach have candidate co-ends `{c₁, …, c_N}`
(N ≥ 2), each an admissible pairing of its open end (Step 1). Suppose the connective **preferred** one,
say `c_i`. A preference is a rule that picks/orders the candidates **consistently** across the
connective — i.e. a **global orientation**: a frame assigning the candidates a consistent order/direction.
The orientations available here are exactly: **σ** — the per-link tag distinguishing a single link's two
readings (source vs target, `DEF_002_010`; `DEF_002_002`). σ is **local** to one link; it does **not**
assign a consistent global order to the candidate co-ends (it says nothing about `c_i` vs `c_j` as
*routes*). A **global** frame — one that would order the candidates — is the **four-cell / observer
layer** (`THM_004_016` n = 4 minimal non-coplanar; `THM_003_012` the 4th is readout; `DISC_002_015`
chirality deferred), which is **not available** at this layer (location relational, no background graph,
`THM_005_020`; and the residual-composition rule that might otherwise structure the candidates is
**deferred**, clause 3 — so it is not part of the connective; and a cell's lineage is to its
source-**entry**, not a cross-cell candidate ordering, `THM_005_021`). Hence **no global orientation is
present**, so no consistent rule distinguishes `c_i` from `c_j`: the candidates are **indistinguishable**,
the admissible-pairing structure is **symmetric** (invariant under permuting `{c₁,…,c_N}`), and **no path
is preferred.** The cells cannot be oriented yet, so there is no difference in which connection path they
take. ∎(2)

**Step 3 (deferral).** The residual-composition rule (`LEM_010_003` OPEN; D-030.Q6) and the observer's
perspective are **not** built. The observer is what later **supplies the missing orientation** — a view
of the symmetric connective (the reframed "collapse"); `THM_005_020` already routes orientation/3D-frame
content to that deferred observer/four-cell layer. NAMED, not built. ∎(3)

**What this proof does NOT use / claim:** no global orientation / frame built (Step 2: named-deferred);
