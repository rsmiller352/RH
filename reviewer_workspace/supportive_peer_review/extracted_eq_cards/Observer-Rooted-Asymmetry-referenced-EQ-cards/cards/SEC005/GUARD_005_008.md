## 1) Plain language

Everything the runtime declares is strictly positive, and the runtime owns no zero to declare. The
residual register holds a strictly-positive amount or is simply absent; a tick posts a
strictly-positive unit or no tick happens (and then no event exists — not a zero counted); the tick
count is a count on record or absent, never "a count of zero." Where the old work read the floor as
"I = 0," this book reads "no posting yet — the record is absent." This card is the runtime fence that
makes the ground rule (stated once at S01) bite at this layer — so a stray zero anywhere in the
runtime is caught.
