## 1) Plain language

The book so far is fixed: every entry of the cell matrix is a settled value or role,
including the void share Ω, which is strictly positive (proved earlier). A book made of
fixed entries can never tell two running situations apart — it has no moving part to
differ by. But the framework is about to run: a closure cycle that keeps turning keeps
producing a small leftover (the residual share Ω, present every cycle and strictly less
than a whole unit), and that leftover has to be held somewhere and let go somewhere. The
fixed book has no place to hold it. So the running cycle forces exactly one new
bookkeeping register into existence — the runtime residual register. This page proves
only that the register MUST exist; what it holds, how it updates, and when it discharges
are the next pages, on purpose.

## 2) Statement

Let the **base/cell data** be the fixed M_cell assignment (DEF_004_020): its entries are
each layer-fixed (designated exact values/counts and the role slot), so the data is a
single fixed datum (THM_003_016(a) at this layer). A **base/cell-functional** is any map
defined on that fixed data alone.

**(a) Constancy (consumed from THM_003_016(a)).** Every base/cell-functional takes
exactly one value: the fixed data has no moving part, so any readout factoring through it
is constant.

**(b) Runtime-register forcing (the theorem).** A **running closure cycle** at fixed
Ω = 1 − π/(3√2) (DEF_004_012, **strictly positive** — no `≥`) accumulates, each cycle, a
strictly-positive residual share and must discharge it across a unit threshold. The pair
(held residual, completed discharge) is a booked distinction between successive runtime
states. By THM_003_016(b) no assignment of base/cell-only readouts distinguishes two
distinct booked states. **Therefore the running closure cycle FORCES exactly one runtime
register beyond M_cell — the residual register** (its partial-holding type is DEF_005_003's
content; its valuation, the recurrence, and the discharge are #5–#9, all at this layer).

**(c) Scoped consequence (forward-flow honest).** S04 does not import the running cycle
as an external given: the cycle is the framework's own closure dynamics, and THM_003_016(c)'s
antecedent "variation is booked" is supplied exactly here by Ω > 0 inducing a per-cycle
residual. The register's CONTENT — what it holds, the update rule, the discharge — is
delivered through this layer's cards #2–#13, one explicit transition card forcing it (this
card), the stack delivering it (THM_003_016 §9's "one explicit transition card").
