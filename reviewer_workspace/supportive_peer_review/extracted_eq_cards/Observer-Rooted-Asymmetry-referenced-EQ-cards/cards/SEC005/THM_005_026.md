# Import-free core recurrence: the base-tick order has no maximal element — ticks recur from the S01 no-terminal/no-last engine + S04 tick-uniqueness, WITHOUT π²-irrationality (IMPORT_004_024) or LEM_005_027; settlement-robust (holds even under exact settlement)

## 0) Governance & Scope Lock

**THM card (S04 recurrence split) — the import-free CORE.** Tick recurrence does NOT require π²-irrationality (`IMPORT_004_024`) or `LEM_005_027`. Recurrence comes from the S01 no-terminal-book engine (`LEM_002_017`) + no-last-realizing-relation (`LEM_002_018`) plus S04 tick-uniqueness (`LEM_005_025`): while admitted content stands, a further licensed entry is forced, and its unique core-S04 representation is the base tick. Exact settlement, rational residual shares, and any future π-free re-grounding do not affect this core. PRE-READOUT (k ≠ n ≠ t); no physical time. Lean: `THM_005_020` not consumed.

Banned: consuming `LEM_005_027` / `IMPORT_004_024`; recurrence-from-arithmetic; a never-exact-settlement or history-recoverability claim (those are `LEM_005_029`, transitional); physical time/clock/rate; tick/escapement conflation; stored zero / signed quantity.

## 1) Plain language

The runtime keeps ticking because the book cannot have a last page. Admitted content cannot be carried to nothing by licensed operations (`LEM_002_017`), and admitted standing content has no last realizing relation (`LEM_002_018`) — a further licensed entry is always forced. At the runtime layer that renewed closure-servicing entry has exactly one licensed form: the base tick (`LEM_005_025`). So after any tick, another tick is forced — the tick order has no last element. This needs nothing about whether the residual share Ω is irrational; it holds even if an account were to settle exactly.

## 2) Statement

For admitted runtime existence, the base-tick order has **no maximal element**.

Equivalently: if admitted content stands at a reachable runtime state, then a further licensed closure-servicing entry is forced (`LEM_002_017`/`LEM_002_018`), and its unique core-S04 representation is a base tick (`LEM_005_025`); hence after any base tick a further base tick is forced. At unit completion the forced event is the escapement/posting `ΔI = 1` (`THM_005_009`/`ROLEDEF_005_018`), not a tick; the posted co-end is admitted standing content, so the reasoning re-applies — recurrence is **settlement-robust** (it holds whether or not any discharge settles exactly). This core is **import-free**: it depends on neither `IMPORT_004_024` nor `LEM_005_027`.

## 3) Input contract (GR-1)

**Consumed (6 edges):** no-terminal-book ← `LEM_002_017`; no-last-realizing-relation (no maximal element) ← `LEM_002_018`; tick-uniqueness (the renewed attempt is one tick) ← `LEM_005_025`; tick/escapement/cell event roles ← `ROLEDEF_005_018`; the forced completed-unit posting ΔI=1 ← `THM_005_009`; the completion output ← `THM_005_010`. **Named (NOT consumed):** `LEM_005_027` (Ω-irrationality — transitional, LEM_005_029's); `IMPORT_004_024` (π² import — transitional); `LEM_005_028` (recoverability — LEM_005_029's); `THM_005_020` (one-cell growth — not needed). **No IMPORT_004_024 / LEM_005_027; no never-exact / recoverability claim; no physical time.**

## 4) Proof

**Step 1.** At any reachable runtime state with admitted content, `LEM_002_017` excludes terminal emptying by licensed operation — the book still holds admitted standing content.

**Step 2.** By `LEM_002_018`, admitted standing content has no last realizing relation: the licensed-entry order has no maximal element — a further licensed closure-servicing entry is forced.

**Step 3.** By `LEM_005_025`, at the core runtime layer the unique licensed representation of that renewed closure-attempt is the base tick. Therefore after any base tick a further base tick is forced: the base-tick order has no maximal element. ∎ (the recurrence)

**Step 4 (settlement-robustness).** If a completion occurs, the forced event is the escapement/posting `ΔI = 1` (`THM_005_009`, `ROLEDEF_005_018`; `THM_005_010` the output), not a tick. The posted co-end is admitted standing content, so Steps 1–3 re-apply. Thus exact settlement, were it to occur, would not create a last tick — recurrence holds whether or not any discharge settles exactly. No step consumes `LEM_005_027` or `IMPORT_004_024`.

It does NOT prove that the native residual never settles exactly (that is `LEM_005_029`, transitional, consuming `LEM_005_027`), does NOT prove history recoverability (`LEM_005_028`, in `LEM_005_029`), and does NOT depend on `IMPORT_004_024` or `LEM_005_027`. It does not consume `THM_005_020`. It does not build physical time, clockhood, frequency, SI units, mass, energy, or a background dynamics.
