## 4) Proof (complete, squeeze)

For every strictly-positive x, ⌊x·Ω⌋ ≤ x·Ω < ⌊x·Ω⌋ + 1 (the floor inequality, DEF_005_006), so
x·Ω − 1 < ⌊x·Ω⌋ ≤ x·Ω. Dividing by x (strictly positive):

$$\Omega - \frac{1}{x} < \frac{N_{\text{tick}}(x)}{x} \le \Omega.$$

As x → ∞, 1/x → 0, so both bounds converge to Ω; by the squeeze, N_tick(x)/x → Ω. ∎

The proof uses only the exact floor inequality and the strict positivity of x — no decimal, no
approximation of Ω. (SWEEP_spine3_C #15 recomputed this squeeze; re-proved on-card.)
