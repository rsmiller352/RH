## 1) Plain language

The runtime needs to turn cycle counts into residual amounts, and amounts back into
counts. Two maps do this: ticking accumulates the residual share Ω per cycle (so x cycles
hold x·Ω of residual), and loading normalizes an amount by the same share. The two maps are
NOT the same operation — counting ticks and counting loads give different numbers, and
conflating them is a known mistake the old work guarded against. This page also does the
one binding the spine has been missing: it states, as an explicit identity, that the
runtime's residual-slot value IS the geometry's void share Ω = 1 − π/(3√2) — three names for
one number (the matrix-slot entry, the runtime valuation, the geometric share). Earlier work
slid this identity in silently and crossed a guard; here it is one honest identity card that
satisfies the guard.

## 2) Statement

**The typed input maps.** For a strictly-positive cycle count x and a strictly-positive load
X (runtime inputs, DEF_005_006's domain):

$$u_{\text{tick}}(x) = x \cdot \Omega, \qquad u_{\text{load}}(X) = \frac{X}{\Omega},$$

feeding the floor/residual operator (DEF_005_006). The **tick count** is

$$N_{\text{tick}}(x) = \lfloor x \cdot \Omega \rfloor$$

— a COUNT READOUT (D-043.Q-c): "no tick posted by x" is the record-absent predicate
(GUARD_005_008), never N_tick(x) = 0. **N_tick ≠ N_load:** the tick-count and load-count
maps are distinct (the SWEEP_spine3_C #22 refusal: N_load(4) = 15 ≠ 1 = N_tick(4)).

**The ω_cell = Ω_pack identity (F-030 repair, D-025.R13).** The runtime residual-slot value
ω_cell, the geometric void share Ω_geom, and the M_cell column entry Ω_cell^slot are **one
number**:

$$\Omega_{\text{cell}}^{\text{slot}} \;=\; \omega_{\text{cell}} \;=\; \Omega_{\text{geom}} \;=\; \Omega_{\text{pack}} \;=\; 1 - \frac{\pi}{3\sqrt2},$$

bound to DEF_004_012's booked residual through the share-split bridge (D + Ω = I). This is
the single sanctioned crossing of GUARD_004_014's slot-valuation fence — an explicit identity
card, satisfying the guard rather than crossing it (the F-020/F-030 lesson). ω_cell inherits
Ω's **support** row-role (M_cell row 3, DEF_004_012 / THM_004_023; finalized D-041,
native re-grounding D-064; read off the row, not by old-derived-N1 inversion).
