# Bounded residual — S_res(k) is strictly positive and strictly below the unit for all k (the 0 ≤ S(k) < 1 re-typed: residue-present predicate / register-absence on discharge, never S_res(k) = 0); induction proof INLINE (F-102)

## 0) Governance & Scope Lock

Lemma with a complete proof INLINE (§4). Exact arithmetic only (symbolic π, √2 where ω_cell
appears). The bound is re-typed per §0: S_res(k) strictly positive when present, register-absent
on exact discharge — never S_res(k) = 0; the upper bound < 1 is the threshold predicate. Serves
named consumers (THM_S04_009/010). Layer ceiling S04.

## 1) Plain language

The residual register never overflows and never goes empty-as-zero. This page proves that at
every cycle the held residue is strictly positive (when it is in the book at all) and strictly
less than one whole unit — because the moment it would reach a whole unit, the discharge fires
and carries the excess as a strictly-positive remainder (or empties the register cleanly,
leaving it out of the book). So the residue lives strictly between nothing-held and a whole
unit, forever: the old "from zero up to one" range, with the zero end re-read as "no residue
held" rather than "a residue of zero."

## 2) Statement

(Native runtime scale; ω_cell = Ω, strictly positive, DEF_005_007.)

For every cycle k, the residual register S_res(k) satisfies the **bounded-residual property**:

- **(present case)** when k ∈ supp(S_res), S_res(k) is **strictly positive** (the residue-present
  predicate — a strictly-positive holding, DEF_005_003) and **strictly below the unit**
  (the threshold predicate S_res(k) ≺ 1); the lower side is the residue-present predicate, never a
  `0 ≤` codomain on the declared register;
- **(absence case)** when a discharge empties the register exactly, k ∉ supp(S_res) — the
  **register-absence predicate** (no residue held), NOT S_res(k) = 0.

The old "0 ≤ S(k) < 1" re-types: the lower bound is the residue-present predicate (when present,
strictly positive) and the register-absence case (when emptied), never the value S_res(k) = 0;
the upper bound < 1 is the threshold predicate (a discharge fires before the unit is reached or
exceeded).

## 4) Proof (complete, INLINE — F-102)

**Base (k = 1).** The runtime starts from the empty-history predicate (no residue held before
the first cycle, DEF_005_003). After the first accumulation, S_res(1) = ω_cell (if no discharge)
or the carried remainder (if ω_cell already crossed a partial start — but with empty history the
first held residue is ω_cell). Since ω_cell = Ω = 1 − π/(3√2) is strictly positive and strictly
below 1 (DEF_004_012's proved bounds 0 < Ω < 1, consumed), the present-case bound holds at k = 1:
0 ≺ S_res(1) ≺ 1. (If the first cycle exactly crossed, the register would be absent — the
absence case; with empty history this does not occur since Ω < 1.)

**Inductive step.** Assume the bounded-residual property at cycle k. By the update rule
(DEF_005_011): S_res(k+1) = S_res(k) ⊕ ω_cell ⊖ [posting].

- **No discharge** (S_res(k) ⊕ ω_cell ≺ 1): then S_res(k+1) = S_res(k) ⊕ ω_cell, which is
  strictly positive (sum of strictly-positive holdings, DEF_002_001 closure) and strictly below 1
  (the no-discharge condition). Present case holds.
- **Strict discharge** (S_res(k) ⊕ ω_cell ≻ 1): the discharge posts one whole unit out
  (THM_005_010), and S_res(k+1) is the existential complement — the unique holding with
  S_res(k+1) ⊕ 1 = S_res(k) ⊕ ω_cell (DEF_002_004). Then S_res(k+1) ≻ 0 (strict case, DEF_002_004
  yields a strictly-positive remainder) and S_res(k+1) ≺ 1 (since S_res(k) ⊕ ω_cell ≺ 2: from
  S_res(k) ≺ 1 and ω_cell ≺ 1, the sum is below two units, so removing one whole unit leaves below
  one). Present case holds.
- **Exact discharge** (S_res(k) ⊕ ω_cell = 1): the register empties — leaves the book (absence
  case, DEF_005_003). No zero value is written.

In every branch the bounded-residual property holds at k+1. By induction it holds for all k. ∎

The proof uses only DEF_002_001's closure/order, DEF_002_004's complement (via DEF_005_011/
THM_005_010), and DEF_004_012's bounds on ω_cell — re-expressed PRESENCE-first (no zero value
anywhere; the absence case is the register-absence predicate).
