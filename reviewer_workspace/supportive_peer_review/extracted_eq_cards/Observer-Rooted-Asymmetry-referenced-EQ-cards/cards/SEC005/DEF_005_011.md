# The update rule (MODEL RULE) — S_res(k+1) = S_res(k) ⊕ ω_cell ⊖ [posting], in transfer form (the −Δ re-grounded as THM_005_010's discharge transfer); self-demotes THM→DEF

## 0) Governance & Scope Lock

Definition card (MODEL RULE, self-demoted THM→DEF): states the runtime update recurrence and
nothing else — the discharge's pairing/balance is THM_005_010's, the bound is LEM_005_013's.
Exact symbolic forms only (π, √2 symbolic where ω_cell appears). The ⊖ is the DEF_002_004
complement (THM_005_010's discharge transfer), never signed subtraction; the carried remainder
is strictly positive when present, or the register leaves the book (DEF_005_003). Layer
ceiling S04.

## 1) Plain language

Each cycle the residual register updates: it takes whatever it held, adds this cycle's share
Ω, and — if that crosses a whole unit — lets one unit go as a discharge, carrying the
remainder forward. This page writes that rule. The "lets one unit go" is not a subtraction
of a negative; it is the discharge transfer from the previous page (one unit out, one unit
into the count). When the crossing is exact, the register empties and simply leaves the book
until residue accrues again — not "a remainder of zero." This is a model rule, not a theorem:
it composes the proved discharge and the proved bound into the runtime's step.

## 2) Statement

(Native runtime scale; ω_cell = Ω, strictly positive, DEF_005_007.)

**The update rule (MODEL RULE, transfer form).** For cycle k:

$$S_{\text{res}}(k+1) \;=\; S_{\text{res}}(k) \,\oplus\, \omega_{\text{cell}} \,\ominus\, [\text{posting}],$$

where:
- ⊕ is the residual accumulation (the conserved-total addition, DEF_002_001);
- **[posting]** is the discharge of THM_005_010 — fired iff S_res(k) ⊕ ω_cell ⪰ 1, posting
  one strictly-positive unit out (the source end) and ΔI = 1 into the event count (the target
  end); ABSENT (no posting) when the threshold is not crossed;
- ⊖ is **NOT signed subtraction**: it is DEF_002_004's **existentially-characterized
  complement** — when a discharge fires, S_res(k+1) is the unique holding whose sum with the
  posted unit restores S_res(k) ⊕ ω_cell (the strict case), or the register **leaves the book**
  when the crossing is exact (the exact case, S_res(k+1) absent). When no discharge fires,
  S_res(k+1) = S_res(k) ⊕ ω_cell (no ⊖ term).

The old "−Δ" re-grounds entirely as the discharge transfer of THM_005_010. The carried
remainder is strictly positive when present, never a zero value.

## 4) Well-formedness (DEF obligation)

- **The rule composes proved pieces.** ⊕ is DEF_002_001's addition; [posting] is THM_005_010's
  discharge (its trigger, double-entry, and balance proved there); ⊖ is DEF_002_004's complement
  (existential characterization in the strict case, register-absence in the exact case). The
  recurrence is therefore well-defined for every cycle: given S_res(k) and ω_cell, the next
  state is determined (the threshold decides whether a discharge fires; the complement determines
  the carried remainder, or absence).
- **No signed object, no zero remainder.** The ⊖ never produces a negative quantity (DEF_002_004
  has no signs) and never a held zero: an exact crossing empties the register (it leaves the
  book — DEF_005_003), and a strict crossing leaves a strictly-positive remainder. The "−Δ" of
  the old work is the source-end reading of the discharge transfer.
- **MODEL RULE status (self-demotion).** This card DECLARES the recurrence; it proves no new
  theorem. The provable content is THM_005_010 (the discharge), LEM_005_013 (the bound), and
  THM_005_015 (the floor-sum keystone reading the recurrence). The type_downgrade is logged
  (frontmatter) — the gen-2 'instinct executed halfway' completed here as an honest DEF.
