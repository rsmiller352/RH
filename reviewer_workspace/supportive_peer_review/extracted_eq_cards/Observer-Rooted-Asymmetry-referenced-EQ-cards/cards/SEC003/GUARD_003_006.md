# Not-physical-time rule — τ and the rank/runtime axis are never measured time; pre-runtime and runtime never conflated; AND the four-rung ladder layer-subscript mixing fence — M_exist/M_base/M_cell/M_rank mix across rungs only through an explicit transition card (D-064: this fence re-homed here from CONV_S02_013)

## 0) Governance & Scope Lock

Prohibition card (GUARD): states one firewall, once; referenced, never restated
(TD-013). Never load-bearing. Single dependency edge by design — the F-100 2-cycle this
card's ancestor carried is deliberately NOT reproduced.

## 1) Plain language

τ is the book's closure cycle — a booked label, not a clock reading. And the runtime
axis that a later section will add (the one whose existence this section proves
necessary) is a bookkeeping axis, not physical time either. Nothing at this layer ticks,
elapses, or is measured. Whenever a derivation starts treating booked cycle labels as
durations, this card is the standing "no."

## 2) Statement (the prohibition, stated once)

1. **τ is never measured/physical time.** τ = 2π is a closure LABEL (DEF_003_002); no
   internal card may read it as a duration, clock output, or temporal coordinate.
2. **The rank/runtime axis is never physical time.** The runtime bookkeeping axis whose
   EXISTENCE THM_003_016 forces (forward pointer — mention, not use) is, when S04
   delivers its content, a bookkeeping axis: rank is not time.
3. **Pre-runtime and runtime are never conflated** (P2): pre-runtime book quantities
   (M_exist/M_base entries) and runtime quantities live at different layers and mix only
   through explicit transition cards.
4. **The four-rung ladder layer-subscript mixing fence (D-064, owned here).** The
   ladder-class objects — **M_exist** (3×1), **M_base** (3×2), **M_cell** (3×3),
   **M_rank** (3×4), each name/shape/content owned by its own DEF (`DEF_003_004`,
   `DEF_003_015`, `DEF_004_020`, `DEF_010_014` — named as forward-pointer fenced objects
   here, NOT consumed) — never appear mixed **across rungs** in a single statement without
   an explicit transition card licensing the step (the F-100 lesson: one transition, one
   card; `THM_003_016` is the S02→S04 axis-existence instance). Registry conformance —
   each ladder name carries its ruled shape, no wrong name/shape pairing, one meaning per
   name (D-030.Q3 / P9) — is machine-enforced by the validator **E-LADDER** rule. This
   clause fences **cross-rung mixing ONLY**; it does not own the matrix names, shapes, or
   content (those are the matrix DEFs'), and is not a general all-layer-discipline rule.

**Exemption:** BRIDGE cards (P7) — any correspondence between τ-counting and measured
time is a translation-map claim, made there with its loss statement.

## 5) Scope & non-overclaim

Fences (i) temporal readings of τ / the rank-runtime axis and (ii) **cross-rung ladder
mixing** (the named clause §2.4). Does NOT own the matrix names, shapes, or content
(those stay with `DEF_003_004` / `DEF_003_015` / `DEF_004_020` / `DEF_010_014`); does NOT
prohibit S04 from defining runtime bookkeeping at its own layer, nor S05+ BRIDGE work from
mapping closure counts to clock readings under an explicit map; and is NOT a general
all-layer-discipline card — it fences only these two named things. Referenced by:
DEF_003_002 §5, THM_003_016 §5 (reminders, no back-edges — the F-100 cycle stays dead).
