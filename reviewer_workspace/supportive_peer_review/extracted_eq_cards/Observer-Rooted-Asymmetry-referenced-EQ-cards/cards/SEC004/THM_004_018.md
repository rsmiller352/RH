# The cell-marking referent (D-033's S03 half, STATIC) — site ↦ cell is a bijection onto the tiling's cells: Vor(λ) = λ + C_u; the referent a posting marks is typed as a site-indexed cell record

## 0) Governance & Scope Lock

Theorem card, STATIC content only: what geometric object a closure posting marks — a
typed referent, proved well-defined. Banned here: posting dynamics, growth order, tick
records, rates, any realization semantics for ledger objects (all S04). Exact
arithmetic only. Layer ceiling S03.

## 1) Plain language

Later in the book, the running machinery will post completed units, and the ruling says
each posting marks a new cell. Before any machinery runs, one static question must have
a clean answer: what IS "a cell" as a markable thing? This page proves the answer: every
lattice site owns exactly one cell — the same rhombic dodecahedron, parked at that site
— different sites own non-overlapping cells, and together they fill everything. So "a
cell record" can safely mean "a site's record": one site, one cell, no ambiguity. When
and how postings happen is the next section's story, on purpose.

## 2) Statement

(Native scale, with the linear scale law as in LEM_004_008 clause 3.)

1. **(Translation equivariance.)** For every $\lambda \in \Lambda_{\mathrm{FCC}}$:
   $\mathrm{Vor}(\lambda) = \lambda + \mathrm{Vor}(0) = \lambda + C_{1/2}$ — every cell
   is a congruent translate of the one proved cell.
2. **(Bijection.)** The map $\lambda \mapsto \mathrm{Vor}(\lambda)$ is a bijection from
   $\Lambda_{\mathrm{FCC}}$ onto the tiling's cells; distinct sites have
   interior-disjoint cells; the cells cover $\mathbb{R}^3$ (THM_004_010 clause 1).
3. **(The static referent, typed.)** Consequently the **cell-record referent** is
   well-typed as a SITE-INDEXED record: $\mathrm{REF}(\lambda) := (\lambda,\ \lambda +
   C_{1/2})$ — one site, one cell, mutually determining. This is the geometric object a
   closure posting marks (D-033's static half). The posting itself — when, whether, in
   what order, with what remainder — is S04-layer content, not touched here.

## 4) Proof (complete)

**Clause 1.** $p \in \mathrm{Vor}(\lambda)$ iff $\|p - \lambda\| \le \|p - \mu\|$ for
all $\mu \in \Lambda_{\mathrm{FCC}}$. Substituting $q := p - \lambda$ and using
$\Lambda_{\mathrm{FCC}} - \lambda = \Lambda_{\mathrm{FCC}}$ (a lattice is its own
translate by a member): the condition reads $\|q\| \le \|q - \nu\|$ for all ν — i.e.
$q \in \mathrm{Vor}(0)$. So $\mathrm{Vor}(\lambda) = \lambda + \mathrm{Vor}(0)$, and
$\mathrm{Vor}(0) = C_{1/2}$ by LEM_004_008 clause 3 (consumed through THM_004_010's
chain). ∎

**Clause 2.** *Injectivity:* $\mathrm{Vor}(0) = C_{1/2}$ is centrally symmetric
(THM_004_007 Step 4: $-C_u = C_u$), so its centroid is $0$; a translate's centroid is
its translation vector; hence the cell determines its site ($\lambda$ = centroid of
$\mathrm{Vor}(\lambda)$) — distinct sites, distinct cells. *Surjectivity:* by
construction the tiling's cells ARE the $\mathrm{Vor}(\lambda)$. *Interior
disjointness and covering:* THM_004_010 clause 1 (consumed: interiors are
strictly-closer sets; covering by nearest-site existence). ∎

**Clause 3.** By clauses 1–2 the pair $(\lambda, \lambda + C_{1/2})$ is well-defined,
and either component determines the other (site → cell by translation; cell → site by
centroid): the record type REF(λ) is unambiguous — a posting that "marks a new cell"
has, at this layer, exactly one well-typed referent class to mark. What performs the
marking, and when, is S04's re-derivation (D-033) — explicitly not decided here, in
either direction (TD-018/TD-022). ∎
