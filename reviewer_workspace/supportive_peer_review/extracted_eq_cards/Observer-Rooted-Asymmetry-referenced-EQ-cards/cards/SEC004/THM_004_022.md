## 1) Plain language

The geometry column's top entry is the **edge** — the shortest bond of the forced lattice, proved
to be **η = √2** (`THM_004_019`), exactly as the base book's top entries are the unit `I` and the
count `c`. Like them, η is an **invariant**: it singles nothing out.

- **No channel.** The edge is the 2-of-3 coupling: `THM_004_021` derives that a cross-cell edge
  "couples exactly 2 of the c=3 channels" — one idle — and that all such couplings are
  interchangeable (a transitive relabeling action; `LEM_003_010`: no channel is invariantly
  distinguished). So the edge picks out no particular channel — it is the *fair* 2-of-3, the same
  fairness that makes `c` distinguish nothing.
- **No absolute scale.** `THM_004_021` proves `η = √2` is a **relational ratio**, not a length:
  the setting is pre-metric, the invariant metric is fixed only up to a content-free scale, so η
  fixes no absolute grid or distance. It is the pure ratio.

And η is not a booked/serviced quantity: `D` (the filled share) and `Ω` (the void share) **carry**
it — the √2 in `D = π/(3√2)` and `Ω = 1 − π/(3√2)` **is** η, and `D + Ω = I` (`DEF_004_020`: "not
independent constants") — exactly as `E`, `G` carry the count `c`. So η, like `I` and `c`,
distinguishes nothing. *Why it matters* (named-forward, not a dependency): the same fairness makes
the observer readout `(c−1)/c = 2/3` observer-independent and the Koide target `K_c = 2/3` stand
(S07). The same reading of S_flow (S07, read via the clockhood role) gives the same answer — the characterization is uniform.

## 4) Proof

**Step 1 (what an invariant is here).** A top-row entry is an **invariant** iff its own forced card
fixes it as a value the rules single nothing out about, and the column entries beneath carry it (it
is not itself a booked/distinguished quantity). Show this of η. ∎(1)

**Step 2 (η's value is forced).** `THM_004_019` forces `η = √2` — "the FCC/RD nearest-neighbor edge
invariant … FORCED (no other value admissible), not assigned" (the minimal nonzero norm of the
forced FCC lattice, `LEM_004_005` + `THM_004_009`). So η is a forced value, not tuned. ∎(2)

**Step 3 (MAKE-OR-BREAK — η singles out nothing).** Two limbs, both forced:
- **No channel.** `THM_004_021 §2(1)`: "an edge couples exactly 2 of the c=3 channels" (1 idle) —
  and (§2(2)) the couplings form a **transitive** `G₃`-action (order 48); `LEM_003_010 §2(c)`: "no
  channel is invariantly distinguished by the rules." Any coupling maps to any other, so the edge
  invariant η picks out no channel — the same fairness that makes `c` distinguish nothing.
- **No absolute scale.** `THM_004_021 §2(4)`: "η = √2 is a relational RATIO" — the setting is
  pre-metric and the invariant metric is dim-1 (forced up to a content-free scale), so η fixes no
  absolute length or grid.
So η singles nothing out. ∎(3)

**Step 4 (∴ η is a top invariant, uniform with I and c).** By `DEF_004_020` the top row is
`[I, c, η]`; by Steps 2–3 η is a forced value the rules single nothing out about, carried by the
column entries beneath it (`D`, `Ω`; `D + Ω = I`; "not independent constants"). So η is an invariant
distinguishing nothing — uniform with `I` (neutral) and `c` (fair). The same characterization
applies to S_flow (S07, read via the clockhood role), carded at its layer. ∎(4)

**Why it matters (named-forward, non-load-bearing).** The same fairness that makes the edge pick out
no channel makes the observer readout `(c−1)/c = 2/3` observer-independent (S07) and the Koide
target `K_c = 2/3` stand; a distinction on a top invariant would break that. Cited as motivation,
**not** consumed (S07 is downstream; forward edge barred).
