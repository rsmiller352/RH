# Overleaf Handoff

1. Upload `Observer-Rooted-Asymmetry-Overleaf.zip` to Overleaf.
2. Open the project and select `main.tex` as the main document.
3. Use pdfLaTeX. No shell escape or external repository is required.
4. Compile. All section, figure, equation, and bibliography inputs are bundled.

The `MATHEMATICAL_AUTHORITY_DIGEST` files are clean publication projections.
The raw closure-complete authority archive is delivered separately and should
not be uploaded as journal-facing manuscript content.
